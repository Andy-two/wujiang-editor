## 二、怎么测

### 1) 🧮 演算台（只算不打）
- 选武将 → 调等级/星级/兵种 → 实时看面板、暴击率、增伤减伤
- **升级曲线图**：1~50 级物攻 / 物防 / 兵力走势，标出当前等级
- **升级效果变化**：`Lv1 → Lv2` 每一维的「改前 → 改后 +差值」；再升 1 星的数值变化
- **技能命中预览**：选技能后显示释放距离/作用范围形状、最远释放格数、倍率、对标准靶的预期伤害或治疗量、Lv 当前与下一级文案

### 2) 🎮 小战场（真的打一局）
- 左侧选敌军类型与敌军等级，点「重置战场」
- 点我方棋子 → 蓝格移动 / 点敌人普攻 / 点技能按钮后点落点
- 右边战报实时记录：移动、普攻、暴击、反击、技能、治疗、击杀、胜负
- `R` 或「结束我方回合」→ 敌军 AI 行动（会靠近、放技能、普攻）
- 战场用的是**你正在编辑的内存数据**，所以改完立刻可测
- **会真正播动画**：移动切「移动」动作、攻击切「攻击」动作、被打切「受击」、死亡停在「死亡」帧，其余时间循环「待机」；朝向自动跟着移动/攻击方向走（缺「右」方向时自动镜像「左」方向）
- **技能会播你导入的特效**：按落点/施法点铺开，逐帧播放一次

### 精灵图：三张图 + 帧号表怎么用
1. 进「⑨ 头像/立绘/精灵图」，**页面最上方是「动作预览与播放」面板**：播放按钮、实时画面、逐帧缩略图都在同一屏
2. 点「▶ 播放所选动作」即按帧号循环播放（待机/移动循环、攻击/受击播一次停住），下方状态栏显示当前播放的动作与方向；点逐帧缩略图可停在某帧细看
3. 中间区域是 **三张图**（攻击图 atk64 / 移动图 mov64 / 特殊图 spc64），可分别导入，会自动识别 64×64 竖排切帧与总帧数；也可一次多选三张批量导入
4. 下方表格是 **5 个动作 × 4 个朝向** 的帧号表，按旧游戏《像素武将角色动画接入说明》铺好默认值：
   - 攻击：下 `1,2,3,4` / 上 `5,6,7,8` / 左 `9,10,11,12` / 右（镜像左）
   - 移动：下 `1,2` / 上 `3,4` / 左 `5,6`；待机：下 `7,1` / 上 `8,3` / 左 `9,5`；受伤 `10,11`
   - 受击用 spc 第 4 帧，防守 1-3 帧、升级第 5 帧
5. 点表格格子选中动作后，可改「所用图片 / 帧号 / 帧率 / 循环 / 水平镜像」；「恢复说明默认帧表」一键还原
6. 没有单独做「右」方向也没关系，小战场会自动左右镜像

> 演示：吕布已用旧素材预设好待机/移动/攻击/受击/死亡，进「⑨」页直接点播放即可看到，进小战场也能看到战斗动画。重新预设可跑 `godot --headless --path . --script res://tools/setup_demo_anims.gd`

### 技能特效怎么用
1. 进「⑥ 技能」，点某个技能的「编辑」，拉到最下面的 **技能特效**
2. 点「导入技能特效图…」选一张特效图（横向帧条或网格），自动估算帧宽帧数
3. 可调：帧宽/帧高/帧数/帧率/**缩放**/**垂直偏移**、**播放位置**（目标格/施法者格/落点格/全部作用格）、**显示层级**（角色之上/角色之下/全屏）、是否与技能等级联动
4. 「▶ 预览播放」直接看；小战场放这个技能时会在对应格子播放

### 伤害公式（三望）

已按你给的公式表重做伤害结算，参数都在「⑪ 全局设定」可调。

**直伤**
```
攻防基础 = 攻 × (1 + 攻击加成 − 攻击降低) × 克制系数 − 防 × (1 − 防御降低) × (1 − 无视防御)
保底     = 攻 × (1 + 加成 − 降低) × 克制 × 破防保底系数 + 1     （默认 0.05，不会为负）
最终伤害 = 攻防基础
         × 攻山倍率（普攻 100% / 技策标注倍率 / 反击 80% / 合击 50% / 追击 100%）
         × 暴击乘区（暴击时 ×暴击倍率，未暴击 ×1）  ← 独立乘区，不参与增伤叠加
         × (1 + 克制增伤)
         × (1 + 攻山类增伤：普攻/追击/反击/技策/战法)
         × (1 + 物/谋元素增伤)
         × (1 + 通用增伤 − 通用减伤)
         × (1 + 最终增减伤)
```

**暴击判定**（独立于伤害乘区）
```
幸运、运势已合并为「魅力」一种属性
暴击率 = 魅力 × 0.7%  +  (自身魅力 − 敌方魅力) × 0.1%  + 附加暴击 − 抗暴率     （上限 100%）
```
> **能不能满爆**：可以，但要堆。魅90 打魅50 ≈ 68.6%，魅100 打魅50 ≈ 75.3%；
> 魅90 再补 **+33% 暴击加成**、魅100 补 **+25%** 即可满爆（「附加暴击率」在⑩扩展里设）。
> 因为含运势差，**高魅力打低魅力更容易暴击，反之更难**：张飞（魅44）打貂蝉（魅95）只有约 30%。

**固伤**（撕裂/溃逃/中毒/敌方兵力）：无视防御和常规增减伤，只吃「固伤增伤」。技能效果块里新增「固定伤害（无视防御）」，可选固定值或按目标最大兵力百分比。

**可调参数**（⑪ 全局设定）：破防保底系数、普攻/反击/合击/追击倍率、暴击倍率、每点幸运/魅力暴击率、魅力爆伤、伤害浮动、最低伤害。

### 五维 → 面板 / 成长 / 战力

**现在武将的兵力、攻防、暴击完全由五维换算，改五维立刻生效**（② 属性页里这几项不再是独立数值）：

| 五维 | 影响 |
|---|---|
| 武力 | 物攻、少量兵力 |
| 智力 | 谋攻、谋防 |
| 统率 | 兵力、物防 |
| 政治 | 谋防、少量兵力 |
| 魅力 | 幸运（暴击率）、暴击伤害 |

- **成长曲线挂钩五维**：五维越高，每级成长越快（≥90 → 1.35 倍，<30 → 0.85 倍），不再所有人一个速度。
- **战力公式**：`(面板战力 + 五维和×14 + 技能战力) × 等级系数 × 星级系数`
  - 面板战力 = 兵力×0.6 + 攻/谋×4 + 防/谋防×3 + 幸运×1.5 + 移动×12 + 射程×18
  - 等级系数 = 1 + (Lv-1)×0.012
  - **星级系数 = 1 + (星-1)^1.55 × 0.16**（升星幅度明显大于升级）
- **② 属性页**显示当前战力，以及「升 1 级 → +N」「升 1 星 → +N」的对比；点升级/升星按钮底部状态栏也会显示 `⚔ 战力 X → Y（+N）`。
- 实测吕布：升 1 级 +158，升 1 星 +1219（约 8 倍），10 星约为 1 星的 6.7 倍。

### 升阶（Lv1/2/3）怎么生效

**文案、效果块、技能范围、天赋 四处都遵循同一条规则：写在哪一级，就从那一级起一直生效到满级。**

| 你在哪一级设置 | Lv1 | Lv2 | Lv3 |
|---|---|---|---|
| Lv1 | ✅ | ✅ | ✅ |
| Lv2 | ❌ | ✅ | ✅ |
| Lv3 | ❌ | ❌ | ✅ |

- **升阶文案**：Lv2 写的"新增效果"对 2、3 级都生效；Lv3 写的只对 3 级生效。技能编辑区显示「当前 Lv%d 生效（逐级累积）」。
- **效果块**：每个效果块有「自Lv」，同上表。
- **技能范围**：⑧ 页升阶 Lv1/2/3 **各自独立存放**——在 Lv2 画范围不会改掉 Lv1 的范围。Lv2 画的范围由 2、3 级共用；只有 Lv3 单独画了，3 级才用 Lv3 的。
- **天赋效果**：同样有「自Lv」，战斗开始时按当前天赋等级过滤后生效。

### 兵种数值如何影响武将

- **移动力 / 射程由兵种统一决定**：「⑤ 兵种」里改盾/枪/弓/骑的基础移动与射程，该兵种所有武将立即同步（②属性页只读显示「6（骑兵 基础 6）」，不能单独改）。
- **普攻范围以你画的为准**：在「⑤ 兵种 → 编辑形状…」画好形状后点 **「保存并同步到武将」**，该兵种所有武将的普攻范围立即变成这个形状，**不会被射程裁剪**（想打更远就把该兵种射程也调大）。
  - 没画形状时，普攻范围按射程自动生成：射程 1 → 十字 5 格，射程 2 → 菱形 13 格。
- **换兵种全部同步**：武将改主兵种后，移动力、射程、普攻范围会一起切换成新兵种的值/形状。
- 技能/天赋写了加成（如「移动 +1」）才在兵种值上叠加。
- **天赋效果**：天赋页添加的效果会自动写入该等级的说明（标注「【效果·天赋LvN】」），战斗开始时按天赋等级生效。

### 技能效果怎么真正改（不只是改描述）

进「⑥ 技能」选中任意技能，编辑区里 **「技能效果（按顺序执行，可自由增删）」** 就是它的真实效果：

- 每个技能由若干 **效果块** 组成，按顺序执行
- 每个效果块都有 **「自Lv」** 生效等级：在 Lv2 时添加的效果，**Lv1 不生效、Lv2/Lv3 生效**；在 Lv3 添加的则只有 Lv3 生效
- 效果块类型（26 种）：
  - 伤害/治疗：造成伤害（倍率/次数/物攻或谋攻/无视防御）、治疗友军、自身回复、持续伤害、持续回复、吸血（伤害转回复）
  - 控制：施加减益、眩晕、嘲讽、封技、缴械、定身类状态（状态名可自由输入）
  - 增益：施加增益、套护盾、提升暴击率、复制/偷取目标增益
  - 调度：击退、位移换位、驱散敌方增益、净化自身减益、自身准备期 -N、获得再移动、额外行动一次
  - 召唤/复活：召唤援军、复活阵亡友军、伤害分摊
- 每块可改数值（倍率、回合、层数、格数、状态名），可 **上移/删除/追加**
- 「复制本技能全部效果…」可把这些效果追加到另一个技能（效果层面的融合）
- **描述文字只是给人看的**；勾选「效果变化时自动写入描述与升级文案」后，描述末尾会自动生成 `【效果】…` 行并同步

### 天赋也能加效果

进「⑦ 天赋」，下方 **「天赋效果（与技能一样可自由添加效果块）」**：同样可选 26 种效果、设「自Lv」生效等级。
天赋效果在**战斗开始时**对自身生效（例如开局给护盾、加增益）。

### 技能合并 / 组合怎么用

进「⑥ 技能」，点右上角 **「⛓ 技能合并 / 组合…」** 打开技能工坊：

1. 工坊里列的是**整个技能库的全部技能**（不再只限当前武将），可搜索技能名 / id / 拥有武将；每行标注「【本武将】」或「拥有：关羽、赵云…」，**可以勾选其他武将的技能来融合**
2. 选模式：
   - **融合成一个技能**：勾选多个后，在「目标技能」里选保留哪个；其余技能的效果（描述、升级文案、被动效果、特效）会并入目标，然后从该武将移除、可选从技能库删除。勾「融合后从技能库删除源技能」即可彻底删除。
   - **做成多选一的组合技策**：填一个名字（如「唇枪舌剑」），勾选的技能会变成一个组合技策；点它时**弹出多选一菜单**，选中哪个就用哪个（各自有自己的 CD 与范围）。子技能定义仍保留在库里。
3. 组合技策在技能列表里显示为 `[组合·多选一] ⇄ 可选：A / B / C`，右侧有「组合 N 项…」按钮可随时增删子技能（数量不限）。

## 四、导出给游戏

点顶部「📦 导出给游戏」：

| 模式 | 用途 |
|---|---|
| 完整（含编辑器字段） | 给自己游戏用，保留 `ed_*` 与全局设定 |
| 旧工程兼容（剥离 ed_*） | 结构与 `sango_wsz_proto/data/*.json` 一致，可直接替换旧工程数据 |
| 精简战斗包 | 只留战斗必需字段 + 兵种系数与克制表 |

可勾选：
- 附带 `range_override.json`（旧工程的范围覆盖文件，可直接读）
- 附带图片（把导入的头像/立绘/精灵图复制到导出目录 `assets/imported/`）

导出实测产物：`generals.json`、`skills.json`、`talents.json`、`settings.json`、可选 `range_override.json`、`assets/imported/*`。

## 五、数据存放

```
data/editor/generals.json   # 武将（旧字段 + ed_* 编辑器字段）
data/editor/skills.json     # 技策
data/editor/talents.json    # 天赋

assets/                     # 旧工程的 56 张武将图、副将图、单位动画、地图底图
```

**字段约定**
- 旧字段原样保留：`id name troop arm color portrait stats{hp,atk,def,matk,mdef,luck,move,range} talent talent_lv talent_desc skills`
- 编辑器新增：`ed_level`、`ed_star`、`ed_skill_lv{}`、`ed_talent_lv`、`ed_art{}`、`ed_ranges{}`、`ed_ext{}`、`ed_note`、`ed_tags`、`ed_enabled`
- 动画：`ed_art.anims["动作_朝向"] = {path, sheet_type, frame_w, frame_h, grid_cols, grid_rows, start, frames, fps}`
- 技能特效：`skills[技能id].ed_fx = {path, sheet_type, frame_w, frame_h, frames, fps, scale, offset_y, anchor, layer, sync_level}`
- 导出的「旧工程兼容」模式会剥离所有 `ed_*`，所以旧游戏不用改代码也能吃

**规则一致性**（与旧工程对齐）
- 升级：每级 兵力+4、四维+1，每 5 级额外 +1
- 星级：每星全属性 ×1.08，兵力额外 +10
- 兵种：盾 1.15/0.95/1.25/1.10、枪 1.05/1.05/1.05/1.00、弓 0.90/1.10/0.90/0.90、骑 1.00/1.10/0.95/0.95（兵/攻/防/谋防），移动/射程加减默认骑移动 +1、其余 0
- 克制：枪克骑、骑克弓、弓克盾、盾克枪；克制方伤害 +25%，被克方受伤 -10%
- 伤害：`atk² / (atk + def) × 倍率`；暴击率 = 幸运 × 0.004 + 魅力 × 0.002，暴击 = 基础 ×1.5 + 魅力 × 0.005
- 范围：`cast` 释放距离形状 + `area` 作用范围形状，按目标方向旋转

## 七、上手三步

1. 打开工程，左侧点「貂蝉」，去「④ 等级/星级」拉到 Lv20、6★，观察「当前生效面板」与「再升 1 级」的变化
2. 去「⑧ 技能范围」，选貂蝉的某个技能，把释放距离改成 5 格直线、作用范围改成 3×3，点「💾 保存」

## 八、注意事项

- 天赋文案里的数值（如「提升15%」）目前只做展示，只有第三节「已真正生效」部分进入引擎计算；旧工程里写死的 100+ 个武将专属天赋没有逐一迁移，需要时可以按 `sango_wsz_proto/scripts/battle_state.gd` 逐个接进来
- 技策库里大部分技策是「通用结算」（单体/范围/控制/治疗），旧工程里少数带 `special` 的专属技策行为没有迁移
- 导入的图片会复制到 `assets/imported/`，Godot 需要重新导入一次（切回编辑器会自动做）
- 「删除武将」立即生效且没有撤销，建议先「保存」或「复制」一份再改
